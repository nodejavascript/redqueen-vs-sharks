What this game knows about you: three letters and a score

That is the honest summary. There is no account, no email, no profile, and no identifier that follows you between visits. If you never enter your initials, this game stores nothing on the server about you at all.

What is stored on the server

When a game ends and you enter three initials, exactly three things are written to the shared scoreboard: the three letters you typed, the score, and the moment it was scored (a timestamp, used only to order two equal scores). Nothing else. There is no name, no address, no device, no location and no cookie attached to that row.

The board is public: it is meant to be. Anyone who opens the site can read every row on it. So type initials you are happy for a stranger to see, and not your full name.

What is stored in your browser

One value, in your browser's local storage: your best score on this device. It never leaves the browser and clearing your site data removes it. There is no tracking cookie, and this site sets none.

What is not done

  • No analytics script loads in this page. There is no Google Analytics on this site.
  • No advertising, no pixel, no third-party script of any kind. The page loads nothing from another origin — the game engine is served from this same site.
  • No profiling, and nothing stored about you is sold, shared or combined with anything else.
  • The server keeps a log of requests, as every web server does, and it is used to keep the site working — not to build a record of who plays.

Children

The game is a game. It asks for nothing from anyone, so a child can play it without giving it anything but three letters, and initials are enough.

Removing your score

Because a row carries nothing that identifies you, it also cannot be found again by looking for you — so the way to remove a score is to name it. Write to antitomato@gmail.com with the three initials and the score, and the row is deleted.
